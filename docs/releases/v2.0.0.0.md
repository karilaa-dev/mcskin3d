# MCSkin3D v2.0.0.0

This release adds an integrated GitHub updater, 3D skin layers, first-person painting, Minecraft lighting controls and faster preview rendering. These notes cover the changes since 1.7.2.

## Automatic updates

- Check the latest stable GitHub release in the background after the editor opens.
- Read the release changelog in the update window, choose **Update and restart**, or **Close** to keep working.
- Use **Skip this update** to remember a skipped version while still receiving later updates. A manual **Help > Check for updates** check includes skipped versions.
- Download and install only when you choose to update. The portable package is checked against its expected size and SHA-256 checksum.
- Stage the update before closing the editor. The normal save prompt protects unsaved edits, and canceling it keeps the editor open.
- Preserve skins, settings, swatches and custom files. Unmodified factory files can be updated from the manifest; modified bundled assets are preserved, and user files are never deleted.
- Back up replaced files and roll back if installation fails. The published portable edition supports automatic installation; source builds offer a manual download.

## 3D skin layers

- Preview hats, jackets, sleeves and trouser overlays with pixel depth, following the 3D Skin Layers mod's geometry and proportions.
- Preserve transparent holes and translucent pixels, with correctly joined cuboid corners.
- Support Steve, Alex, legacy hat layers and higher-resolution skins, including Skin + Cape workspaces.
- Paint directly on raised pixels; painting, erasing and undo refresh the geometry.
- Configure individual layers, pixel/head/body scales and render distance under **Options > 3D Skin Layers settings**.
- Adjust 3D render resolution from **50–200%** and antialiasing to **Off, 2x, 4x or 8x**, subject to graphics-driver support. The texture sheet stays at native resolution.
- Keep the original skin PNG and model unchanged: layer and quality options affect the preview.

## Minecraft lighting

- Apply Minecraft-style lighting to ordinary skins, flat overlays, raised layers, first-person hands and combined accessories, independently of 3D Skin Layers.
- Adjust world-light **Brightness** from **0–15**, with a default of **15** (full daylight) and ambient light retained at level 0. Existing saved light levels are preserved. Game brightness is fixed at 100%.
- Rotate the **Lighting angle** from **-90° to 90°**, using the slider or degree field. **Default** restores **0°** without changing brightness.
- Choose whether the background and grass are dimmed with the skin using **Surroundings**.
- Switch lighting off to preview the original texture colors.
- Keep lighting preferences when switching views, toggling layers or resetting layer settings.
- Use compact, stacked lighting controls and clearer toolbar icons, with values preserved when controls hide in 2D view.

## First-person preview

- Preview and paint the selected skin's right or left hand and sleeve from Minecraft's first-person perspective.
- Support Steve, Alex, legacy player models and higher-resolution skins.
- Remember the selected hand between launches, with the right hand selected initially.
- Use the resting empty-hand pose and fixed 70° projection, with the selected arm's own texture coordinates.
- Keep sleeves flat in first person while preserving the raised-layer setting for the regular 3D view.
- Preserve the orbit camera when switching views and keep painting coordinates stable when toggling lighting or layers.
- Paint and undo directly on the visible hand. Unsupported models return to the regular 3D view.

## Performance and polish

- Reuse unchanged preview textures, transparency data and layer geometry.
- Reduce redundant GPU readbacks during hover previews.
- Refresh caches after editing, resizing, reloading and settings changes, while retaining geometry for color-only edits.
- Expand regression coverage for rendering, picking, settings, layout and editor integration.
- Update the source-build SDK baseline to **.NET 10.0.404**.

## Downloads and upgrading

**Portable Windows x64 is the only download:** `MCSkin3D-2.0.0.0-win-x64.zip`. It includes the .NET runtime; no separate runtime installation is needed. For a fresh installation, extract the complete archive into a writable folder and run `MCSkin3D.exe`.

**The first upgrade from 1.7.1 or 1.7.2 is manual.** Their update checker opens the GitHub release page but cannot install this upgrade.

For an existing installation from the supplied **1.7.2 portable ZIP**, save your work, close all editor instances, and back up the application folder. Extract 2.0.0.0 into a separate folder, then copy only these files into the corresponding locations in your existing installation:

| Action | File | Purpose |
| --- | --- | --- |
| Replace | `MCSkin3D.exe` | Required editor update; includes the runtime. |
| Add | `update-channel.txt` | Required for future automatic updates. |
| Add | `update-manifest.json` | Required for future automatic updates. |
| Replace if unmodified | `Languages/English.lang` | Updated English labels; retain customized catalogs. |
| Replace, optional | `changes.txt` | Updated release notes. |
| Replace, optional | `readme.txt` | Updated package instructions. |

The executable alone upgrades the editor; both metadata files enable its automatic installer. Older English catalogs use embedded fallback text for new controls. Leave `settings.ini`, `Skins`, `Swatches`, `Models`, `Overlays`, custom language files and every other existing file untouched. The other **175 files are byte-identical** to the original 1.7.2 ZIP; no removals are needed. Future releases can be installed through the new update window.

The existing Skin + Cape workspace, shared chronological undo/redo, continuous elytra spread slider and read-only official cape gallery remain available; they were already part of 1.7.2.
