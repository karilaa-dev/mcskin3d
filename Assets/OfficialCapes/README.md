# Official cape reference assets

Minecraft cape artwork belongs to Mojang Studios / Microsoft and its respective creators. These PNGs are reference artwork for local previews, separate from the editor's GPL source code. This catalog does not grant ownership or equip capes in Minecraft.

`catalog.xml` records each texture's download URL, a catalog/reference URL, release date, and SHA-256 checksum. All 51 retained PNGs were re-fetched and matched byte-for-byte on September 17, 2026: 48 from Mojang's `textures.minecraft.net`, the two historical holiday originals from the Minecraft Wiki archive, and the Progress Pride archive below. These resources are embedded, never copied as loose PNGs or a separate catalog folder into the release.

The current Java designs were cross-checked against [NameMC's observed cape catalog](https://namemc.com/capes) and [Craftdex](https://craftdex.net/capes). The historical [Bacon cape](https://mcprofiles.me/capes/official/bacon) was granted and later revoked. [Contemporary holiday records](https://www.minecraftforum.net/forums/minecraft-java-edition/discussion/120498-list-of-official-minecraft-cloaks) document Christmas 2010 and New Year 2011. [Progress Pride](https://minecraft.wiki/w/Progress_Pride_Cape) is an official Bedrock cosmetic; its texture is archived at [NovaSkin](https://minecraft.novaskin.me/post/6498733139/progress-pride-cape-bedrock-edition). Blueprint is also community-named [Document](https://namemc.com/cape/f249694c066c160c). The developer [Test / size-m cape](https://mcprofiles.me/capes/official/test) is explicitly an API test, not an official cosmetic, and has been removed along with its asset. OptiFine designs, other API tests, fan-made designs and April Fools textures are not included.

Dates use the original release in either Java or Bedrock, not later cross-edition availability or download dates. Restricted staff/personal capes use their documented first appearance. A year-only date means the exact day is not documented; those entries sort at the start of that year. Same-date entries sort by name. Hero and Twisted are real, [officially announced Java/Bedrock capes](https://www.minecraft.net/en-us/article/minecraft-dungeons-ii-capes-promos); their entries use the announced September 29, 2026 public launch date rather than a staff preview sighting. Legacy Console skin-pack costumes are separate content.

To update the catalog, verify the cape's provenance, add an unmodified compatible PNG and a manifest entry with a unique stable ID, display name, source/reference URLs, SHA-256 checksum and release date (`yyyy-MM-dd`, or `yyyy` for uncertain historical dates). The gallery always includes every entry, sorted newest to oldest. Run `./build.ps1`; the smoke suite decodes every texture, checks verified checksums, chronology and read-only protection, and renders the native gallery. The graphics suite additionally exercises official references in the real viewport.
